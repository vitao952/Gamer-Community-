Comandos para CMD

Comandos de limpeza

%temp%

O comando %temp% no Windows 10 não é exatamente um comando, mas sim uma variável de ambiente. Quando você digita %temp% em um prompt de comando ou na barra de endereços do Explorador de Arquivos e pressiona Enter, você está acessando a pasta temporária do usuário atual do Windows. Essa pasta temporária, também conhecida como pasta de arquivos temporários, é usada pelo sistema operacional e por programas instalados para armazenar arquivos temporários durante a execução. Esses arquivos podem incluir caches de programas, arquivos temporários de instalação, arquivos de registro e outros dados temporários que são usados durante o funcionamento normal do sistema ou de aplicativos. A pasta %temp% é limpa periodicamente pelo sistema operacional, mas ocasionalmente pode ser necessário limpá-la manualmente para liberar espaço em disco ou resolver problemas de funcionamento de aplicativos. Em resumo, o comando %temp% no Windows 10 é uma forma rápida de acessar a pasta temporária do usuário atual, onde são armazenados arquivos temporários utilizados por programas e pelo sistema operacional.

Comandos para Agendar Desligamento

Com o CMD aberto em modo ADM, insira o seguinte código e dê enter:
  • desligar na mesma hora: shutdown -s -t 0
  • desligar em 1 minuto: shutdown -s -t 60
  • Para desligar em 1 hora: shutdown -s -t 3600
  • Para desligar em 2 horas: shutdown -s -t 7200
  • Para desligar em 3 horas: shutdown -s -t 10800
  • Para desligar em 4 horas: shutdown -s -t 14400
  • Para desligar em 5 horas: shutdown -s -t 18000
  • Para desligar em 6 horas: shutdown -s -t 21600
  • Para desligar em 7 horas: shutdown -s -t 25200
  • Para desligar em 8 horas: shutdown -s -t 28800
  • Para desligar em 9 horas: shutdown -s -t 32400
  • Para desligar em 10 horas: shutdown -s -t 36000
  • Para cancelar o desligamento: shutdown -a
